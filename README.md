# POS Manager · VAN 대리점 가맹점 관리 웹앱

포스·카드단말기·키오스크를 설치하는 VAN 대리점에서 일하며 직접 겪은 문제를 풀려고 만든 사내용 웹앱입니다.

## 왜 만들었나

- **정보가 흩어져 있었다:** 가맹점 정보가 네이버 밴드, 엑셀, 구글 시트, 카카오톡에 나뉘어 있었고, 기존 엑셀의 약 4,000건은 형식이 제각각이었다.
- **주소 찾기가 일이었다:** 방문할 때마다 주소를 일일이 찾아야 했다. 주소가 틀렸거나, 지도·웹에 나오지 않거나, 엑셀에서도 빠진 가맹점이 있었고, 복사·붙여넣기도 매끄럽지 않았다.
- **전화 온 가맹점을 바로 찾을 수 없었다:** 누가 전화했는지 알아도 그 가맹점 정보를 찾으려면 따로 검색해야 했다.

→ 가맹점·장비·작업 이력을 **한곳에서 관리**하고, 방문할 가맹점을 골라 **바로 길안내**하고, **전화가 오면 해당 가맹점이 바로 뜨는** 시스템을 목표로 했다.

## 개발 과정

코딩 경험 없이 2026년 봄 약 한 달 이상, 퇴근 후 Gemini와 245번의 대화로 만들었다. 기획과 테스트는 직접, 코드 작성은 AI가 했다. **이 저장소의 첫 커밋은 당시 코드 그대로(API 키만 제거)이고, 이후 커밋은 코드를 직접 분석하며 개선한 기록이다.**

과정, 실패 원인, 배운 점은 [개발 회고](docs/retrospective.md)에 정리했다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 가맹점 검색·등록·상세 | 상호명·사업자번호·대표자명 검색, 기본정보 / 비용·약정 / 장비 / 작업이력 4개 탭 |
| 장비 관리 | VAN사 → 모델 순서로 선택, 설치·교체·해지 이력 |
| 작업 이력·업무 | 완료/예정 구분, 담당자, 작업 유형, 사진 첨부, 내 예정 업무 대시보드 |
| 전화 수신 연동 (시제품) | 가맹점에 설치하던 CID 장비를 PC에 연결해, 걸려 온 번호가 저장된 번호면 해당 가맹점 화면으로 바로 이동. 저장되지 않은 번호면 통화 중·후에 기존 가맹점에 연결하거나 신규 등록. 현재는 예시 번호로만 동작 |
| 경로 담기 | 방문할 가맹점을 담고 순서 변경 (길안내 연동은 개선 계획 3번) |

## 실행 방법 (Windows)

1. [Python](https://www.python.org/downloads/)을 설치합니다. 설치할 때 **Add python.exe to PATH**를 체크합니다.
2. 이 폴더에서 명령 프롬프트를 열고 아래를 차례로 실행합니다.
   ```
   pip install -r requirements.txt
   python seed.py
   python app.py
   ```
   `seed.py`는 가상의 가맹점 5곳과 데모 계정을 만듭니다. 처음 한 번만 실행하면 됩니다.
3. 브라우저에서 `http://localhost:5000`에 접속해 **demo / demo1234**로 로그인합니다.

> 내 계정을 따로 만들려면 `python make_user.py`를 실행합니다. `start.bat`을 더블클릭해도 실행되지만, 윈도우 스마트 앱 컨트롤이 막는 경우가 있어 위 방법을 권장합니다.

**기술:** Python · Flask · SQLite · HTML/CSS/JavaScript · TMAP API
